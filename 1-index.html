Reusable equipment components

Each piece is a self-contained module with its own parameters (length, width, height, speed), so a new layout is assembled from parts rather than redrawn.

Roller conveyor

Powered rollers with animated rotation, accumulation and spacing so boxes queue up the way they do on a real line.

Chain conveyor

Twin-strand chain with moving links and sprockets, elevated on a supported frame with guard rails.

VRC (vertical lift)

Vertical reciprocating conveyor with a carriage, mast frame and a load / lift / unload / return cycle.

Rack storage + dispatch

18-slot rack with put-away and retrieval, a pick lift and a dispatch conveyor to the outbound truck.

Next in roadmap

Profile checker

Height / width gate that measures each load and rejects out-of-profile cartons to a reject lane.

Live demo: intake to dispatch

Trucks unload onto the roller line, the lift raises each carton to the chain conveyor, the rack stores it, and dispatch orders send it to the outbound truck. Every control on the right works. Drag to orbit, scroll to zoom, hover a box to see its SKU.

Built to plug into your existing 3D module

Components are plain JavaScript classes on Three.js, so they drop into an existing scene. Data moves in and out as simple files.

Layout import / export

Equipment settings, enabled state and stored stock are saved to JSON and restored on import.

Inbound manifest (CSV)

Upload a SKU / quantity list and the cartons arrive on the line in that order.

Event log and snapshots

Every put-away, pick and dispatch is logged and exportable, plus a one-click PNG of the current view.

Light and fast

Single-page, no heavy assets: about 0.8 MB total, runs smoothly on laptops and phones.
